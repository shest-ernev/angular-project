# Тестовое задание

Небольшой frontend-проект на Angular с использованием Taiga UI. Проект представляет собой упрощенный сервис для управления каталогом товаров, работы с корзиной и просмотра истории покупок. Так же это мой первый опыт разработки на angular.

## Что было реализовано

### 1. Авторизация

Разработана страница авторизации, которая закрывает доступ к основным страницам сервиса. В форме авторизации есть поля логина и пароля. Валидация формы реализована с использованием Reactive Forms.

Валидация полей:

- все поля обязательны для заполнения;
- минимальная длина пароля - 8 символов;
- пароль может содержать только латинские буквы и цифры.

Для управления авторизацией и сохранения состояния входа в `localStorage` был написан сервис `AuthStoreService`. При успешной авторизации пользователь перенаправляется на страницу каталога. Если логин или пароль введены неверно, отображается уведомление через Taiga UI Toast.

Данные для входа:

- логин: `test`;
- пароль: `Test1234`.

### 2. Роутинг и защита страниц

В проекте настроены маршруты для страниц авторизации, каталога и истории покупок. Доступ к страницам каталога и покупок защищен через `authGuard`.

Логика защиты:

- неавторизованный пользователь перенаправляется на страницу входа;
- авторизованный пользователь не может повторно открыть страницу входа и перенаправляется в каталог;
- после выхода из аккаунта пользователь возвращается на страницу авторизации.

### 3. Страница каталога товаров

Разработана страница каталога с таблицей товаров. В таблице отображаются ID, название, цена, НДС и доступные действия для каждого товара.

На странице каталога реализованы:

- просмотр списка товаров;
- добавление нового товара;
- редактирование существующего товара;
- удаление товара;
- добавление товара в корзину и удаление из корзины.

Список товаров хранится в `ProductsStoreService`. Данные каталога сохраняются в `localStorage`, поэтому изменения не теряются после перезагрузки страницы.

### 4. Создание товара

Для добавления товара реализовано диалоговое окно Taiga UI. Форма создания товара содержит поля названия, цены и НДС.

Валидация формы создания:

- название обязательно для заполнения;
- цена обязательна и должна быть больше нуля;
- НДС обязателен и должен быть в диапазоне от 0 до 100.

Числовые поля по умолчанию пустые, чтобы в них отображался placeholder.

### 5. Редактирование товара

Для редактирования товара реализовано отдельное диалоговое окно Taiga UI. При открытии формы поля заполняются текущими данными выбранного товара.

В форме редактирования используется такая же валидация, как при создании товара. После сохранения данные товара обновляются в каталоге и сохраняются в `localStorage`.

### 6. Удаление товара

Перед удалением товара добавлено диалоговое окно подтверждения с использованием компонента Taiga UI. Товар удаляется только после подтверждения действия пользователем.

### 7. Корзина

Реализован дополнительный функционал в проекте. В шапке приложения реализована корзина в виде выпадающего блока Taiga UI. В кнопке корзины отображается количество добавленных товаров.

В корзине реализованы:

- просмотр добавленных товаров;
- отображение цены и НДС по каждому товару;
- отображение общей суммы товаров без учета НДС;
- удаление товара из корзины;
- оформление покупки.

Для управления корзиной был написан сервис `CartStoreService`. Состояние корзины сохраняется в `localStorage` и очищается после оформления покупки.

### 8. Покупки

При нажатии на кнопку покупки все товары из корзины добавляются в историю покупок. Для хранения истории используется `PurchaseStoreService`.

В истории покупок сохраняются:

- ID покупки;
- названия купленных товаров;
- логин покупателя;
- сумма покупки с учетом НДС;
- дата операции.

История покупок отображается на отдельной странице в виде таблицы и сохраняется в `localStorage`.

### 9. Шапка приложения

Реализована общая шапка приложения с навигацией между страницами каталога и покупок. Также в шапке находятся корзина и кнопка выхода из аккаунта. Активные ссылки выделяются нижнем бордером и цветом текста.

Для мобильной версии реализовано бургер-меню. При открытии меню прокрутка страницы блокируется.

### 10. UI и технологии

В проекте используются standalone-компоненты Angular, Angular Signals, Reactive Forms и компоненты Taiga UI.

Из Taiga UI используются:

- кнопки;
- поля ввода;
- диалоговые окна;
- подтверждение действия перед удалением;
- выпадающий блок корзины;
- уведомления;
- scrollbar для таблиц.

### 11. Страница 404

Реализована страница 404 если пользователь попадёт на несуществующий роут. На странице так же реализована ссылка на существующую страницу в зависимости от ваторизации польщователя.

## Основные технологии

- Angular;
- TypeScript;
- Reactive Forms;
- Angular Signals;
- Taiga UI;
- `localStorage` для хранения состояния приложения.
